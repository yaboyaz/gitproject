# Pocket Weather

A lightweight, mobile-friendly weather web app powered by the free Open-Meteo API. Look up any city or use your phone's location to see the latest conditions.

## Features
- City search with automatic geocoding
- One-tap "Use my location" for quick updates
- Current conditions including feels-like, humidity, wind, and precipitation
- Responsive layout that fits comfortably on phones and tablets

## Usage
1. Open `index.html` in your browser (or serve the folder with `python -m http.server 8000`).
2. Search for a city or tap **Use my location** and approve the permission prompt.
3. Review the current temperature, description, and supporting metrics.

No API keys or accounts are required.
